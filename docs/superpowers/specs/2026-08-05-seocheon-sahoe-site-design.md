# 서천 지역화 자료 사이트 — 설계 문서

- **작성일**: 2026-08-05
- **목적**: 초등학교 3학년 사회 교과서(출판사별)와 서천교육지원청 발행 「우리 고장 서천」 지역화 학습자료를 연결해, 교사가 어떤 출판사 교과서를 쓰든 자신의 진도 차시에 맞는 서천 지역 자료(이미지·PDF·영상·QR 링크)를 바로 찾아 활용할 수 있게 하는 웹사이트.

## 1. 배경과 범위

- 사용자는 서천교육지원청 소속 장학사/교사로, 매년 「우리 고장 서천」 지역화 학습자료(대단원-소단원-차시 구조)를 발행한다.
- 문제: 학교마다 채택한 사회 교과서 출판사가 달라, 같은 지역화 자료라도 출판사별로 몇 단원 몇 차시에 해당하는지 다르다. 교사들이 이를 매번 스스로 대조해야 하는 번거로움이 있다.
- 이번 1단계 범위: **실제 콘텐츠 없이, 사이트의 틀(구조)만 먼저 구현**한다. 즉 출판사 선택 → 대단원 → 소단원 → 차시 탐색 UI, 자료 슬롯(이미지/PDF/영상/QR) 표시 틀, 로그인 게이트, 퀴즈 자리 예약까지 만들고, 실제 최신 자료·정확한 출판사 목차는 추후 채워 넣는다.
- 범위 밖(향후 단계): 실제 자료 업로드, 정확한 전체 출판사 목차 반영, 퀴즈 문항 제작, 관리자 콘텐츠 편집 UI(Firestore 연동), 교사/학생 권한 차등화.

## 2. 기술 스택 & 아키텍처

- **프론트엔드**: React + Vite (SPA), React Router
- **호스팅**: GitHub Pages (GitHub Actions로 자동 빌드/배포)
- **백엔드**: Firebase
  - Firestore: 접근 게이트용 비밀번호 설정(`config/access` 문서) 저장. 콘텐츠 자체는 1단계에서 Firestore를 쓰지 않는다.
  - Firebase Authentication(이메일/비밀번호): 관리자 로그인 전용
- **콘텐츠 데이터**: 저장소 내 JSON 파일로 관리 (아래 3절). 관리자 페이지 없이 개발자(Claude Code)가 직접 파일을 편집·커밋한다.
- **이미지 자료**: `public/images/...` 경로에 저장소 내 직접 포함해서 GitHub Pages로 서빙한다. (Firebase Storage는 2026-02-03부터 Blaze 유료 플랜 연결이 필수가 되어 사용하지 않음 — 참고: https://firebase.google.com/docs/storage/faqs-storage-changes-announced-sept-2024). 업로드 전 웹용 압축/리사이즈 권장.
- **PDF·영상 자료**: 구글 드라이브, 유튜브 등 외부 링크 + QR 링크로 연결(파일을 사이트에 직접 올리지 않음).
- **규모 검토(200명, 비동시 접속 위주)**: Firestore/Firebase Auth 무료(Spark) 플랜으로 충분. 별도 결제 등록 불필요.

## 3. 데이터 모델 (JSON)

```
src/data/
├── publishers.json
├── curricula/
│   ├── jihak.json
│   ├── chunjae.json
│   └── (추후 출판사 추가)
├── topics.json
├── mappings.json
└── quizzes.json
```

### publishers.json
```json
[
  { "id": "jihak", "name": "지학사" },
  { "id": "chunjae", "name": "천재교과서" }
]
```

### curricula/{publisherId}.json
출판사별 실제 교과서의 대단원 > 소단원 > 차시 구조.
```json
{
  "publisherId": "jihak",
  "units": [
    {
      "id": "u1",
      "title": "1. 우리가 사는 곳",
      "order": 1,
      "subunits": [
        {
          "id": "u1-s1",
          "title": "(1) 우리 주변의 장소",
          "order": 1,
          "lessons": [
            { "id": "u1-s1-l1", "title": "여러 장소에 대한 경험과 느낌 떠올리기", "order": 1 }
          ]
        }
      ]
    }
  ]
}
```

### topics.json
서천 지역화 자료(원본 콘텐츠) 단위. 대단원/소단원/차시제목은 첨부된 실제 자료집 목차를 그대로 사용.
```json
{
  "id": "topic_1-1-1",
  "대단원": "1. 우리가 사는 곳",
  "소단원": "(1) 우리 주변의 장소",
  "차시제목": "여러 장소에 대한 경험과 느낌 떠올리기 ①",
  "활용법": "",
  "resources": [
    { "type": "image", "title": "", "src": "" },
    { "type": "pdf", "title": "", "url": "" },
    { "type": "qr", "title": "", "url": "" }
  ]
}
```

### mappings.json
topic ↔ 출판사별 차시를 N:M으로 연결하는 핵심 연결 고리.
```json
[
  { "topicId": "topic_1-1-1", "publisherId": "jihak", "lessonId": "u1-s1-l1" },
  { "topicId": "topic_1-1-1", "publisherId": "chunjae", "lessonId": "u2-s1-l1" }
]
```

### quizzes.json
지금은 빈 배열로 자리만 예약. `scope`가 `subunit`/`unit`이면 하위 차시 문제들을 모아서 보여주는 방식으로 구현(차시당 약 2문항 → 소단원은 그 소단원의 차시 문항 모음 → 대단원은 그 대단원 전체 문항 모음).
```json
[]
```

## 4. 페이지 흐름 & 라우팅

```
/login                              교사/학생 공용 비밀번호 입력 (통과 시 세션 저장)
/                                   출판사 선택 화면 (카드 그리드 + 서천 읍면 일러스트 지도 배경)
/p/:publisherId                     대단원 목록
/p/:publisherId/:unitId             소단원 목록
/p/:publisherId/:unitId/:subunitId  차시 목록
/p/:publisherId/:unitId/:subunitId/:lessonId
                                    차시 상세: 매핑된 topic 자료 카드 + 활용법 + 퀴즈 버튼(자리만)
/quiz/:scope/:refId                 퀴즈 화면 (scope=lesson|subunit|unit), 지금은 "준비 중" 표시
/admin/login                        관리자 로그인 (Firebase Auth)
/admin                              관리자 대시보드 (1단계에서는 최소 기능만, 콘텐츠 편집 없음)
```

## 5. 주요 컴포넌트

- `PublisherSelector`: 출판사 카드 그리드, 선택 시 localStorage에 저장해 재방문 시 기억
- `UnitBreadcrumb`: 대단원 > 소단원 > 차시 경로 + 뒤로가기
- `LessonList`: 차시 카드 목록 (제목/번호/자료 유무 뱃지)
- `ResourceCard`: 자료 슬롯 표시 (이미지/PDF/영상/QR 타입별 아이콘). 자료가 비어 있으면 "자료 준비 중" 빈 상태 디자인 표시
- `QuizPlaceholder`: 퀴즈 버튼 클릭 시 "준비 중" 안내 + scope별 예정 문항 수 안내

## 6. 인증/접근 제어

- 교사용 비밀번호와 학생용 비밀번호를 각각 별도로 둔다(`config/access` 문서에 `teacherPasscode`, `studentPasscode` 두 필드). 로그인 화면에서 둘 중 어느 것을 입력해도 통과되며, 통과 시 로컬스토리지에 unlocked 플래그(+ 어떤 비밀번호로 들어왔는지 role 값)를 저장한다. 클라이언트에서 Firestore 값과 직접 비교하는 방식으로, 민감 정보가 아닌 공개 교육자료 게이트 목적이므로 이 수준으로 충분하다.
- 교사/학생 접근 시 보이는 콘텐츠는 현재 동일(구분 없음). 추후 역할 구분이 필요해지면 세션에 role 필드만 추가하면 되도록 스키마에 여지를 남겨둔다.
- 관리자: Firebase Authentication(이메일/비밀번호)로 별도 로그인. 비밀번호(교사용/학생용/관리자 계정) 변경은 **Firebase 콘솔에서 직접 재설정**하며, 사이트 내에는 비밀번호 변경 UI를 만들지 않는다.

## 7. 비주얼 디자인 방향

- 톤앤매너: 따뜻하고 귀여운 느낌. 첨부된 서천 지역화자료 표지의 오렌지/민트 그라데이션, 둥근 말풍선, 연필 마스코트 캐릭터 스타일을 참고해 일관성 유지. 둥근 모서리, 부드러운 그림자, 파스텔+웜톤 색상 사용.
- 출판사 선택 화면(`/`) 배경: 서천군 13개 읍면(서천읍·장항읍·마서면·화양면·기산면·한산면·마산면·시초면·문산면·판교면·종천면·비인면·서면)을 대략적으로 나눈 **일러스트 스타일 지도**를 낮은 투명도(약 8~15%)로 배경에 배치. 실측 GIS 데이터가 아닌 간단화된 형태이며, 정밀한 행정경계가 아님을 감안한다.
- 세부 색상 팔레트·폰트·지도 일러스트 형태 등 픽셀 단위 디자인 결정은 구현 단계에서 frontend-design 스킬을 통해 구체화한다.

## 8. 출판사 교과서 목차 데이터 (1단계 처리 방식)

- 정확한 출판사별 실제 교과서 목차는 웹 검색만으로 100% 정확히 확보하기 어렵다는 것을 확인함(출판사가 상세 목차를 공개하지 않는 경우가 많음).
- **1단계**: 지학사, 천재교과서 등 샘플 출판사 2~3곳의 `curricula/{publisherId}.json`을 첨부된 서천 지역화자료 실제 목차(대단원/소단원/차시)를 기준으로 **플레이스홀더**로 채워 넣는다. 데이터 안에 "실제 교과서와 다를 수 있음" 주석/필드를 남긴다.
- **추후**: 사용자가 전체 출판사별 실제 진도표(차시별 매핑 파일)를 제공하면, 그 파일을 분석해서 각 `curricula/{publisherId}.json`과 `mappings.json`을 정확한 값으로 갱신한다. 이는 별도 작업으로 진행하며 이번 1단계 구현 범위에는 포함하지 않는다.

## 9. 이번 단계에서 하지 않는 것 (Out of scope)

- 실제 자료(이미지/PDF/영상 링크) 채워 넣기 — 자리(틀)만 만든다.
- 전체 출판사(10곳 이상)의 정확한 목차 반영 — 샘플 2~3곳 플레이스홀더만.
- 퀴즈 문항 제작 — 데이터 구조와 "준비 중" UI만.
- Firestore 기반 콘텐츠 관리자 페이지 — 향후 단계.
- 교사/학생 콘텐츠 권한 차등화 — 향후 단계.
- 관리자 비밀번호 변경을 위한 사이트 내 UI — Firebase 콘솔에서 수동 처리.
