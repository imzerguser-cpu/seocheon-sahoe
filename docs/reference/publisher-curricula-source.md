# 3학년 사회 전체 출판사 진도표 — 원본 시트 추출 보고서

이 문서는 Google Sheet "사회 전체 출판사 진도표"의 전체 텍스트를 추출·파싱한 결과를 정리한 참고 자료입니다.
추후 실제 JSON 데이터 파일(예: 각 출판사별 대단원/소단원/차시 데이터, `mappings.json` 등)을 만들 때 원문 그대로 사용할 수 있도록,
모든 단원/차시 제목은 시트에 기재된 원문 그대로(의역·요약 없이) 옮겼습니다.

## 3. 모호성 및 데이터 품질 이슈 (반드시 확인 필요)

1. **출판사명 완전 결측**: `grep`으로 "출판사", "천재교과서", "금성", "지학사", "비상교육", "미래엔", "동아출판", "김영사", "아이스크림" 등 모든 알려진 출판사명을 검색했으나 추출된 텍스트(fileContent) 전체 어디에도 매치되지 않았습니다. Google Sheet의 `read_file_content` 추출 결과는 여러 개의 마크다운 표를 이어붙인 순수 텍스트였고, 표와 표 사이에는 공백 줄만 있을 뿐 탭 이름이나 출판사 라벨이 포함되어 있지 않았습니다. 원본 스프레드시트에 다음 중 하나가 있을 가능성이 높습니다: (a) 출판사명이 각 시트 탭(worksheet) 이름으로만 존재하고 이 텍스트 추출 방식은 탭 이름을 포함하지 않음, (b) 표 위에 병합된 헤더 셀/텍스트 상자로 출판사명이 있었으나 텍스트 추출 시 누락됨, (c) 색상 코딩 등 비텍스트 방식으로만 구분됨. **원본 시트를 직접 열어 8개 블록이 등장하는 순서대로 탭 이름 또는 헤더를 확인하여 A~H 라벨을 실제 출판사명으로 치환해야 합니다.**

2. **소단원(중단원) 열 없음**: 요청하신 "대단원 → 소단원 → 차시" 3단 구조에 해당하는 전용 "소단원" 컬럼이 시트에 존재하지 않습니다. 대신 각 차시 행에는 성취기준 코드(9번 컬럼, 예: `[4사01-01]`)가 달려 있고, 동일 성취기준을 공유하는 연속된 차시들이 사실상 소단원처럼 묶여 있습니다. 이 보고서에서는 이 성취기준 단위를 **"성취기준 그룹"**이라는 이름으로 소단원 대용으로 사용해 하위 목록을 구성했습니다 — 이것은 원본 시트의 명시적 데이터가 아니라 이 보고서 작성 과정에서 추론한 그룹핑이므로, 실제 `mappings.json` 등에 소단원명을 넣어야 한다면 원본 교과서를 별도로 확인해야 합니다.
3. **지역화 자료 매핑 없음**: 시트 전체에서 "지역화", "지역화 자료" 등의 문구나 특정 출판사 차시에 지역 자료 주제를 연결하는 열/구간은 발견되지 않았습니다. `mappings.json` 작성에 필요한 지역화 자료 매핑 정보는 이 시트에는 포함되어 있지 않은 것으로 보입니다.
4. **블록 간 차시 수 불일치**: 8개 블록의 단원별 차시 수가 서로 다릅니다 (예: `일상에서 만나는 과거` 단원이 블록별로 25~30차시로 편차가 있음). 이는 8개가 서로 다른 실제 교재(출판사)임을 뒷받침하는 근거로 보이며, 단순 복제/중복 데이터는 아닌 것으로 판단됩니다.
5. **원본 파일 인코딩 이슈(해결됨, 참고용 기록)**: 최초 PowerShell `Get-Content | ConvertFrom-Json` + `[System.IO.File]::WriteAllText`로 추출을 시도했을 때 한글이 심하게 깨졌습니다(예: `?곕━媛 ?щ뒗 怨?`). 원본 JSON 파일의 바이트를 직접 검사한 결과 파일 자체는 정상적인 UTF-8이었고, 문제는 PowerShell 5.1의 JSON/파일 인코딩 처리 과정에서 발생한 것이었습니다. **Python (`json.load` + UTF-8로 파일 쓰기)으로 재추출하여 문제를 해결**했습니다. 이 보고서의 모든 한글 텍스트는 재추출된 정상 UTF-8 데이터를 기반으로 합니다.
6. **페이지 범위 결측 1건**: 파싱된 4행 컬럼(페이지) 중 전체 734개 차시 행 가운데 1개 행만 페이지 값이 비어 있었습니다 (거의 완전한 데이터).
7. 위 성취기준 그룹 라벨(`[성취기준 그룹 N]`)의 번호는 각 대단원 내에서 순서대로 매긴 것이며, 원본 교육과정 성취기준 번호 체계(예: 4사01-01, 4사01-02)와는 별개로 이 보고서 안에서만 사용하는 편의상 번호입니다. 실제 성취기준 코드는 각 그룹 제목의 대괄호 안에 그대로 표기했습니다.
